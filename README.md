# qatt-chunom-apk: two keyboard experiments, archived side by side

Two attempts at an Android keyboard that types like Gboard (Vietnamese Telex, English, German, …) and has a composition field (pencil ✎) in which Quốc Ngữ is typed with Telex and turned into Chữ Nôm, QATT and PA. Both work in parts, neither is finished; they are kept here as they were left (November 2026).

| Folder | Base | State |
|---|---|---|
| [`heliboard/`](heliboard/) | HeliBoard 4.3-beta1 (GPL-3.0; AOSP LatinIME) | Many languages, dictionaries and suggestions from the base. The composition field (candidates PA / QATT / Chữ Nôm, Space modes, fonts, text or image sending) and a Telex without composing text. **Not stable**: the cursor jumped and extra characters appeared on long Backspace (also in German); the settings are overloaded. |
| [`floris/`](floris/) | FlorisBoard `main` at `bac346e` (Apache-2.0; the unfinished rewrite "keyboard3") | Stable in use, but the base is a skeleton: one hard-coded layout, no dictionaries, no suggestions. Added: five layouts (DE, EN, VI, FR, ES), a globe key next to the comma, the composition field (floating frame, switches PA / 喃 / QATT, a three-place candidate bar, Telex, closes after sending). |

## What is reusable (pure Kotlin, no Android)

`TelexKey` (port of `VietIme.telex` of `js/ime.js`, golden test of 165,222 cases in `heliboard/app/src/test`), `ComposeField` / `ComposeSession`, `NomDictionary` (from `dict.csv` and `ime.js`), `PaText`, `QattText`, `VietnameseParser`, `ViSuggester` (completions of the ≤7 letters before the cursor), the word lists, and the notes in [`heliboard/docs/`](heliboard/docs/) (`plan.md`, `port.md`: also the approaches that failed).

## Build

Each folder builds on its own (`ANDROID_HOME` set): `cd heliboard && ./gradlew assembleDebug`; `cd floris && ./gradlew :app:assembleDebug` (needs the NDK and CMake 4.1.2 from the SDK manager).

## FlorisBoard changes

`floris/qatt-changes.patch` is the diff to upstream `bac346e` (without the data files); the new code is in `floris/app/src/main/kotlin/dev/patrickgold/florisboard/qatt/`, the layouts are generated by `floris/qatt-tools/gen_layouts.py`, the data and fonts (QATT Pen and PA Pen, see `LICENSE.txt` there) are in `floris/app/src/main/assets/qatt/`.
